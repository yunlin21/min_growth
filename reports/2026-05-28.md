### 1. 飞书 (Feishu/Lark) 网关配置

**问题**: 通过飞书发送的消息 Agent 没有收到

**排查过程**:
- 检查网关状态 → 运行中但飞书未连接
- 检查配置 → `.env` 中 `FEISHU_APP_ID`、`FEISHU_APP_SECRET` 已配置
- 发现核心问题: `lark-oapi` SDK 未安装，导致 WebSocket 连接失败
- 发现第二个问题: `FEISHU_ALLOW_ALL_USERS=false` 且白名单为空，所有消息被拒绝

**解决方案**:
```bash
# 安装飞书 SDK（使用阿里云镜像）
pip install lark-oapi

# 修改 .env 配置
FEISHU_ALLOW_ALL_USERS=true

# 重启网关
hermes gateway restart
```

**结果**: ✅ 飞书 WebSocket 成功连接 `wss://msg-frontier.feishu.cn/ws/v2`

**关键知识点**:
- Hermes 飞书适配器依赖 `lark-oapi` Python 包
- 国内 pip 安装可能需要换源（阿里云镜像）
- 用户白名单配置决定消息是否被 Agent 接收

## 🎯 核心知识点总结

### Hermes 架构理解
1. **Gateway 模式**: 消息平台网关是多进程的，每个平台独立连接
2. **技能系统**: 技能 = SKILL.md + 可选脚本/模板，存储在 `~/.hermes/skills/`
3. **配置层次**: `.env` (密钥/开关) vs `config.yaml` (行为配置)
4. **日志位置**: `~/.hermes/logs/gateway.log` 是排查消息问题的第一站

### 排错经验
1. **网关问题排查顺序**: `hermes gateway status` → `grep 平台名 gateway.log` → 检查 SDK 依赖
2. **国内网络**: pip 安装可能超时，需要 `--index-url https://mirrors.aliyun.com/pypi/simple/`
3. **配置生效**: 修改 `.env` 后必须重启网关 (`hermes gateway restart`)

### WSL2 环境
- 网关以手动进程模式运行，需要 tmux 保持持久化
- Windows 文件系统通过 `/mnt/c/` 挂载访问
